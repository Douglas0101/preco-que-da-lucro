# S-SEC — revisão fixa hPanel — 2026-09-09

## Pergunta

CP-1 está seguro para inserir env vars?

## Veredito

**RED — não está seguro para inserir env vars neste momento.**

Base do veredito:

- A1 registra que não havia classic branch protection nem ruleset configurado observável; portanto não há proteção de branch demonstrada que autorize tratar checks como required (`docs/evidence/hpanel-preview-2026-09-09/artifacts/A1-branch-protection-before.md:6-8`).
- O estado B1 do Web App ainda tinha `Variáveis de ambiente: Nenhum` e o próprio artefato conclui que CP-1 não estava satisfeito (`docs/evidence/hpanel-preview-2026-09-09/artifacts/B1-hpanel-onboarding-before-submit.md:6-18`, `:20-25`).
- A branch Neon de homologação foi criada, mas é uma cópia do estado atual do parent `production`, em plano Free, com retenção de histórico de 6 horas; isso é existência de branch, não validação de configuração, retenção ou readiness para CP-1 (`docs/evidence/hpanel-preview-2026-09-09/artifacts/B2-neon-branch-created.md:3-16`).
- O contrato local exige variáveis no runtime web e determina que URLs administrativas e variáveis de migration não sejam entregues ao processo web (`docs/runbooks/hostinger-cloud-node.md:116-132`). O runbook de homologação também exige conferir apenas nomes e manter os nomes administrativos/legados/migration ausentes no web (`docs/runbooks/hpanel-homologacao.md:17-17`).

Assim, inserir env vars agora não tem pré-condições suficientes demonstradas: faltam a configuração efetiva do conjunto mínimo, a prova de separação entre web e migration/admin e a proteção de branch. A ausência de valores no artefato é positiva quanto à não exposição, mas não é evidência de configuração segura.

## Valores, masking e exposição

- A1 confirma que nenhum valor de env, token, cookie, URL com credencial ou segredo foi coletado (`docs/evidence/hpanel-preview-2026-09-09/artifacts/A1-branch-protection-before.md:21-25`).
- B1 confirma que nenhum valor de env, token, cookie ou URL com credencial foi coletado ou gravado (`docs/evidence/hpanel-preview-2026-09-09/artifacts/B1-hpanel-onboarding-before-submit.md:20-26`).
- B2 confirma que a string de conexão apareceu mascarada na UI e que nenhum valor de senha, URL completa, token ou segredo foi lido, copiado ou exibido (`docs/evidence/hpanel-preview-2026-09-09/artifacts/B2-neon-branch-created.md:18-22`).
- Portanto, os três artefatos revisados não contêm valores de env/segredos; quando a conexão foi exibida, foi mascarada. Isso comprova contenção de exposição nos artefatos, não presença/configuração correta no hPanel.

## Gaps que impedem CP-1

1. B1 ainda registra zero variáveis configuradas; não há evidência do conjunto mínimo esperado presente.
2. Não há evidência, nos artefatos revisados, da separação efetiva entre env do web e env de migration/admin.
3. A1 não demonstra branch protection/ruleset; checks visíveis no PR não podem ser promovidos a required por ausência de regra observável.
4. B2 demonstra a criação da branch Neon, mas não demonstra conectividade do Web App, `DATABASE_URL` pooled correta, `DATABASE_DRIVER`, readiness saudável, RLS/roles ou migrações aplicadas na branch de homologação.
5. A branch Neon tem retenção observada de 6 horas e expiração automática; a adequação dessa retenção ao objetivo de homologação não foi ratificada no material revisado (`docs/evidence/hpanel-preview-2026-09-09/artifacts/B2-neon-branch-created.md:10-15`).
6. O contrato ainda exige confirmação externa de injeção de porta/host, proxy, processo persistente e reinício no hPanel (`docs/runbooks/hostinger-cloud-node.md:43-49`, `:206-217`); esses fatos não estão demonstrados pelos três artefatos.

## Limite operacional

Esta revisão foi somente leitura local dos três artefatos hPanel/Neon indicados e dos dois contratos locais indicados. Não houve navegação, inspeção de credenciais, leitura de valores de env ou modificação de qualquer arquivo além deste handoff.

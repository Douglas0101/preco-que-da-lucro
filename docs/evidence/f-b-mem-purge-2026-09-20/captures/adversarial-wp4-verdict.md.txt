## C2 — Ordem de `MEMORY_TRAIL_TABLES` é FK-safe — **CONFIRMED**

Inventário de vínculos das 5 tabelas (schema; confere com 0017/0018/0019):

| tabela | FK | destino | onDelete |
|---|---|---|---|
| `ai_memory_access_log` | (tenant_id,user_id) | memberships | **RESTRICT** (`schema.ts:1288-1291`; 0019:30) |
| `ai_memory_conflicts` | tenant_id / (tenant_id,memory_id) | tenants / memories | CASCADE (`1203`) / **RESTRICT** (`1214-1217`; 0018:29) |
| `ai_memory_versions` | tenant_id / (tenant_id,memory_id) | tenants / memories | CASCADE (`1165`) / **RESTRICT** (`1181-1184`; 0018:31) |
| `ai_memory_sources` | tenant_id / memory_id / conversation_id / message_id / product_id / simulation_id / user_id | tenants / memories / chat_conversations / chat_messages / products / simulations / memberships | CASCADE em todas (`1088, 1104-1127`; 0017:48-54) |
| `ai_memories` | tenant_id / (tenant_id,user_id) | tenants / memberships | CASCADE (`1006, 1050-1053`; 0017:46-47) |

A ordem `access_log → conflicts → versions → sources → memories`:
- `access_log` sem filhos e sem FK para memories/tenants; tem de sair antes de **qualquer** delete de memberships/tenants/users (os três caminhos batem no RESTRICT). Primeiro lugar é correto e obrigatório.
- `conflicts` e `versions` **RESTRICT** para `memories` ⇒ antes de `memories` é obrigatório.
- `sources` **CASCADE** para `memories` ⇒ sair antes é redundante, porém determinístico (SPEC §2 declara isso).
- `memories` é o pai; nada referencia `access_log`, nem `sources`/`versions`/`conflicts` além das FKs listadas (busca por `foreignColumns: [aiMemories` retorna só `1106/1183/1216`; nenhuma FK para `aiMemoryAccessLog`).
- Vínculos "das 5 para memberships/tenants": cobertos ao remover as 5 antes de `tenant_memberships`/`tenants`/`users`; nenhum `RESTRICT` sobra. Nada fora das 5 referencia as 5.

Veredicto: a ordem cobre todos os vínculos entre as 5 e destas para memberships/tenants; a única aresta que **exige** precedência é `access_log` (memberships), `conflicts`/`versions` (memories) — todas respeitadas.

## WP-9.2T — desacoplar o **tipo** de `RequestContext.transaction` do driver (dono: SQUAD-APP)

| campo                  | conteúdo                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **spec_ref**           | `MEDICAO-2026-09-15.md:109` ("contextos são tipados pelo driver (`RequestContext.transaction`…)") · `PLANO:790-802` (§9.2 "contratos independentes de driver") + `:804-815` (§9.3 contexto) · `V7:2521` · resíduo **R3** do veredicto `CLAIMS-INBOX/WP-9.2R-VERDICT.md` (prova: `tsc` com `@/db/*` remapeado ⇒ TS2307 em `src/lib/request-context.ts:1,42`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **problema**           | O contrato de repositório é independente de driver **em runtime** (o bundle do contrato tem 0 bytes e nenhum import de `@/db`), mas o **grafo de tipos** ainda alcança `@/db/client.server` porque `RequestContext.transaction` é tipado pelo driver (Drizzle). Quem consome o contrato **para tipar** acaba dependendo do driver — é literalmente o que o item `9.2` nomeia, e é o que **impede o item de fechar**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **DoD (explícito)**    | (1) `RequestContext` (ou o tipo que ele expõe para transação) deixa de referenciar tipos do Drizzle: provado por **`tsc` com remapeamento de `@/db/*`** — nenhum erro em `src/lib/request-context.ts` nem nos contratos/repositórios do agregado (o teste A/B do verificador vira asserção). (2) Os **contratos** de repositório seguem driver-agnostic (type-only, sem `@/db`/`drizzle-orm`). (3) O **BFF não importa `@/server/repositories/**`** e nenhum módulo de cliente carrega handler/import server indevido — `npm run build` **exit 0** e `grep -rn "@/server/repositories" src/lib/*.functions.ts` vazio. (4) `import-protection` **permanece fail-closed** (nenhum ajuste de configuração que afrouxe o gate). (5) Testes existentes verdes **sem alterar asserção**; testes de fronteira/build novos quando aplicável. (6) `npm run check` + `npm run db:test` verdes no HEAD integrado. |
| **risco principal**    | `RequestContext` é infraestrutura usada por **todos** os serviços/repositórios — a mudança é de **tipo**, não de runtime, mas um erro de assinatura propaga. Mitigação: mudança **aditiva** (introduzir o tipo neutro e migrar consumidores por etapas), `tsc` como rede, e **nenhuma** mudança de comportamento em runtime (nenhum SQL, nenhuma query, nenhuma transação alterada).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **testes exigidos**    | (a) O teste A/B de tipos: um arquivo de teste que **remapeia `@/db/*`** e falha se o contrato/contexto voltar a alcançar o driver (o próprio verificador já provou que o método funciona); (b) os 5 arquivos do agregado + `contracts.test.ts` verdes sem alteração de asserção; (c) `npm run build`; (d) `npm run m02:boundaries`; (e) `grep` de resíduo (BFF→repositories = 0) e de `drizzle-orm`/`@/db` nos contratos = 0.                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **E1/E2**              | **E1:** vitest dirigido + `npm run build` + `tsc` + `m02:boundaries` + os greps; **E2:** `npm run check` + `npm run db:test` no HEAD integrado (container PG17 virgem).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **escopo (exclusivo)** | `src/lib/request-context.ts` · `src/db/client.server.ts` (**só** a parte de tipagem exposta ao contexto, se necessário) · `src/server/contracts/*.ts` · os repositórios/serviços que consomem o tipo (migração mecânica) · `src/test/*contracts*.test.ts` · `docs/evidence/agent-state/CLAIMS-INBOX/WP-9.2T.md`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

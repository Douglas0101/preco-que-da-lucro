# Evidência de progresso P0 — 2026-08-13

Este registro descreve o estado local após a execução incremental do plano, sem
afirmar cutover ou release concluídos.

## Gates locais executados

- `npm run check`: concluído com sucesso (format, lint, typecheck, 206 testes,
  build Nitro `node-server` e bundle abaixo de 500 kB no grafo inicial).
- `node scripts/check-no-supabase-runtime.mjs`: passou; Supabase permanece
  permitido apenas como origem de migração read-only documentada.
- Preview local: o build agora gera `.output/server/index.mjs` com preset
  `node-server`; o sandbox desta execução não permite bind de socket, portanto
  o Playwright local não foi usado como evidência de browser.

## Fechamentos implementados nesta etapa

- CI usa `nitro preview` e o preset Node, eliminando a divergência entre
  `dist/server/server.js` e `.output/server/index.mjs`; `npm audit` foi movido
  para antes do E2E para não desaparecer quando o webServer falhar.
- `GET getChatHistory` passou a ser somente leitura; `createChatConversation`
  e envio/reset são os caminhos POST que podem criar a conversa. O teste de banco
  `scripts/db/test-chat-semantics.ts` verifica que a contagem não muda no GET.
- Escritas de produto, preço, ingredientes, embalagem, taxas e despesas exigem
  role `owner` ou `admin`; há teste unitário de negação para `member`.
- CSP deixou de permitir `unsafe-inline` em scripts e estilos.
- Dimensão `production`, contexto de conversão persistido e o aceite de
  break-even `10,1 → 11` foram adicionados ao motor/testes.
- Dashboard ganhou repositório/service e resumo agregado server-side; simulação
  manual passou a chamar o BFF financeiro. Saídas de tools têm schema Zod,
  sanitização e validação também em replay; texto da IA é sanitizado antes da
  persistência.
- Break-even passou a usar `calculateBreakEven` no BFF, com `rawUnits` e
  `roundedUnits` como strings decimais e arredondamento `ceil` para unidades
  indivisíveis; a tela não chama mais o motor diretamente.
- O chat agora tem uma FSM explícita (`idle`, `thinking`, `tool_calling`,
  `waiting_user`, `error`) e o estado de erro encerra o indicador de digitação.

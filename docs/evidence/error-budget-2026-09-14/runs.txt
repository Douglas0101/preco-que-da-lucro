# §30 — Error budget: transcrição de execução e códigos de saída observados

- Data: 2026-09-14 (UTC).
- Ambiente: `dev-evidence` **local-first** — sem banco, sem rede e sem origem de produção.
- Runtime: node v24.15.0 · tsx ^4.23.12 (devDependency) · `prettier` só para formatar o `.md`.
- Worktree: `.worktree-onda2-budget`, branch `ops/onda2-budget` (base `9f8280e`).
- Insumos: fixtures versionadas em `src/test/fixtures/error-budget/` (`basic-7d.jsonl`,
  `financial-invalid.jsonl`, `insufficient.jsonl`) e o input sintético desta pasta,
  `demo-ok-24h.jsonl`, usado apenas para exibir o caminho verde (exit 0). Não é baseline.
- Cada bloco traz o comando exato, o stdout integral e o código de saída observado.
- `artifacts/` é o scratch gitignored (`docs/evidence/**/artifacts/`) das provas de
  local-first; o que vale como fonte é este `.txt` e os `.md`/`.json` versionados na pasta.

## 6) dump JSON do mesmo relatório (raw machine-readable)

O `.md` é o artefato canônico; o `.json` homônimo é o mesmo `ErrorBudgetReport`
serializado pela função exportada `buildReport`, sem regra de negócio nova. Harness
(definido uma vez, colável):

$ dump_report() {
    local name="$1" input="$2"; shift 2
    node --import tsx --input-type=module -e '
  import { buildReport, parseArgs } from "./scripts/obs/error-budget.ts";
  import { readFileSync } from "node:fs";
  const [input, ...argv] = process.argv.slice(1);
  const report = buildReport(readFileSync(input, "utf8"), parseArgs(argv), input);
  process.stdout.write(JSON.stringify(report, null, 2) + "\n");
  ' "$input" "$@" > "docs/evidence/error-budget-2026-09-14/$name.json"
  }

$ dump_report basic-7d src/test/fixtures/error-budget/basic-7d.jsonl --window=7d
  (exit=0) basic-7d.json: FAIL/1 classes=financial_critical:OK,ai_transient:DRAFT,server_fault:EXHAUSTED
$ dump_report financial-invalid src/test/fixtures/error-budget/financial-invalid.jsonl --window=7d
  (exit=0) financial-invalid.json: FAIL/1 classes=financial_critical:EXHAUSTED,ai_transient:UNKNOWN,server_fault:EXHAUSTED
$ dump_report insufficient src/test/fixtures/error-budget/insufficient.jsonl --window=7d

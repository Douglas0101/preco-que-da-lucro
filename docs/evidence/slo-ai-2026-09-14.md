## 2. IA — fases da latência do chat não-streaming

- **Regime:** CONTROLADO (mock) — gateway mockado com atraso simulado e banco em memória; não é produção.
- **Método:** `npx tsx scripts/obs/ai-latency-baseline.ts --runs=50 --delay-ms=40`, executando o fluxo real de `executeSendChatMessage` com o harness `src/test/helpers/chat-execution-fakes.ts`, no relógio `performance.now()` do processo; cada fase é lida do próprio instrumento de produção.
- **N:** n = 50 execuções por cenário (6 séries × 50 amostras, todos os 50 registros presentes em cada série).
- **Janela (UTC):** 2026-09-14T03:37:50.815Z → 2026-09-14T03:37:56.921Z.
- **Fonte bruta:** `docs/evidence/slo-ai-2026-09-14/ai-latency-controlled.json`.

| Cenário         | Fase (série)                   |   n |    min |    p50 |    p75 |    p95 |    max |
| --------------- | ------------------------------ | --: | -----: | -----: | -----: | -----: | -----: |
| mock-no-tool    | `app.ai.time_to_acknowledge`   |  50 | 39.235 | 40.330 | 40.440 | 41.090 | 42.357 |
| mock-no-tool    | `app.ai.time_to_first_content` |  50 | 39.334 | 40.456 | 40.591 | 41.229 | 42.595 |
| mock-no-tool    | `app.ai.time_to_final`         |  50 | 39.334 | 40.456 | 40.591 | 41.229 | 42.595 |
| mock-tool-round | `app.ai.time_to_acknowledge`   |  50 | 39.341 | 40.289 | 40.389 | 41.102 | 41.875 |
| mock-tool-round | `app.ai.time_to_first_content` |  50 | 79.885 | 80.832 | 81.146 | 81.942 | 82.751 |
| mock-tool-round | `app.ai.time_to_final`         |  50 | 79.885 | 80.832 | 81.146 | 81.942 | 82.751 |

- **Cenários:** `mock-no-tool` = um round de gateway sem tool; `mock-tool-round` = uma tool call determinística + round final (dois rounds). Atraso simulado do provider: 40 ms por round.
- **Leitura honesta:** o valor absoluto é o atraso simulado somado ao overhead de orquestração. O sinal medido é o overhead p75 acima do simulado até a fase: `time_to_acknowledge` 0.440 ms (sem tool) e 0.389 ms (com tool); `time_to_first_content` = `time_to_final` 0.591 ms e 1.146 ms. A instrumentação do §29 custa ~0,4–1,2 ms p75 nos dois cenários.
- **Fora do escopo medido:** transporte HTTP/TTFB do BFF, latência real do provider de IA, I/O de PostgreSQL real.
- **Não-streaming:** `time_to_first_content == time_to_final` hoje — as amostras das duas séries são idênticas neste raw — e as séries continuam separadas para receber streaming sem renomear série.
- **Cobertura de instrumentação:** histogramas `app.ai.time_to_acknowledge` / `app.ai.time_to_first_content` / `app.ai.time_to_final` (`src/instrumentation/telemetry.ts`), campos `timeToAcknowledgeMs` / `timeToFirstContentMs` / `timeToFinalMs` no log `ai.chat_completed` e spans `ai.chat.send` / `ai.chat.round` (`src/lib/chat-execution.server.ts`), cobertos por `src/test/ai-chat-latency.test.ts`.
- **Provider real (IA):** OBSERVED-UNAVAILABLE — H-6 (tráfego real autorizado) pendente; nenhuma amostra OBSERVED existe e nenhum rótulo CONTROLADO é emitido para provider real.

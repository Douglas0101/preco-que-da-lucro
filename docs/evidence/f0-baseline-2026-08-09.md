## F0-03 — Golden tests do Financial Engine

`src/test/finance.golden.test.ts` — 19 testes cobrindo os 12 casos do Plano §5, incluindo os cenários canônicos da Diretriz §12 (R$ 10 → prejuízo R$ 1.800; R$ 11 → R$ 1.100). Comportamentos atuais incorretos estão assertados e marcados com `golden:` + lote de correção:

- custo faltante → 0 (lote 04); unidade incompatível → 0 (lote 08);
- yield zero → custo 0; yield null → 1 (lotes 07/08); tax null → 0 % (lotes 04/05);
- break-even impossível → `Infinity` sem ceil discreto (lote 09, FIN-08 da V7).

Gate da FASE 0 atendido neste item: refatoração do motor só após golden tests — existem e estão verdes.
